\# Vowel Counter



A simple console application written in Java to count and analyze vowels in a text.



\## Features



\- Counts total vowels and displays individual character breakdown 

\- Handles case-insensitivity (supports both uppercase and lowercase input)

\- Runs in a loop until the user chooses to exit



\## How to Run



Make sure you have the JDK installed, then run:



```bash

cd vowelcounter/src

javac vowelCounter.java

java Main
